# 制約と適用範囲

## 未リリース

npm パッケージは未公開で、**実機での動作確認もまだありません** — iOS シミュレータと
Android エミュレータのみです。

## 現在描けるもの

Normal / Mesh / Shape / Instance / Effect の各パーツ。Normal と Shape のターゲットに
対するマスクとクリッピング。フレームバッファのブレンドテーブル全種。PartColor。
13 個の `ss-*` 統合シェーダー。オーバーライドレイヤー。ユーザーデータ・オーディオ・
シグナルのイベント。アニメーションライフサイクル。`fit`/`align` による配置。リソースと
アトラスのキャッシュ。`<SpriteStudioScene>`。Expo config plugin。

## 未対応

- **`Nines` と `Text`** パーツ。
- **マスクされた Mesh と Effect** — どちらも*マスクなし*で描画されます。マスクの
  リプレイは、1 つのアフィン四角形の UV を逆算してカバレッジのサンプル位置を決めます。
  メッシュはそのテクスチャ座標チャンネルを自身のアトラスに使っており、エフェクトは
  1 つの四角形ではなく四角形の群れです。
- **呼び出し元のマスクが届いている間の、子自身のマスク writer。** 呼び出し元のカバレッジ
  が引き渡され、子はそれを参照します。その結果、子自身の writer はそのフレームでは何も
  書きません。SDK はこの 2 つを「別のトラック」と呼んでおり、この移植版は 1 本しか
  走らせていません。外部からマスクが届かない限り、自分自身をマスクするサブアニメー
  ションは影響を受けません。
- **Reanimated ティック** — パーツのトランスフォームは既に shared value として公開されて
  いますが、フレームループはまだ JS スレッド上の `requestAnimationFrame` です。

## プラットフォーム

| | |
|---|---|
| iOS / Android | サポート対象 |
| web | **何も描画されません** — ただしこのパッケージを入れても web ビルドは壊れません。web 用のエントリはスタブなので、native と web の両方を出荷するアプリのバンドルは通り、throw するのはそこでプレイヤーを描画したときだけです。web 上の SpriteStudio は [SSPlayerForWeb](https://github.com/cri-middleware/SSPlayerForWeb) です。 |
| macOS | 単に動く可能性があります — RN Skia と Nitro はどちらも対応しています。CI 対象外、保証なし。 |
| tvOS / visionOS | ランタイム側でブロックされています。Rust のターゲットが Tier 3 で、SDK の XCFramework にスライスがありません。 |
| Windows | 手段がありません — Nitro も RN Skia も react-native-windows に対応していません。 |

## Expo Go と Fast Refresh

Expo Go はこのパッケージを実行できません。ネイティブコードを含むため prebuild が必要
です。またパックはバンドルのエントリではなくアプリのアセットなので、**アセットの変更には
ネイティブビルドが必要**です — アセットは Fast Refresh されません。

## 信頼できないパック {#untrusted-packs}

`source` には `http(s)` URL を指定できるので、ここは正確に述べる価値があります。

**バッファはネイティブランタイムに渡る前に検証されます。** 途中で切れたダウンロード、
書きかけのキャッシュ、意図的に壊された `.ssab` は、パースされる前に拒否されます。

**参照グラフは検証されません。** 自分自身のアニメーションをマウントする Instance パーツ
には有限の展開が存在せず、スタックが尽きるまで再帰することを止めるものはありません。
これは意図的な非目標です。どのパックを再生するかはアプリ自身の裁量であり、循環参照は
その作者がエディタ上で確認できるコンテンツ側の不具合だからです。

つまり、構造は検査されますが内容は検査されません。実行時に `.ssab` をダウンロードする
アプリなら、自分で管理している経路で配信してください。
